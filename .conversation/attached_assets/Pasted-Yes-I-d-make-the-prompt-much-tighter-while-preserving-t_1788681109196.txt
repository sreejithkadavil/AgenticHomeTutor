Build a scalable web-based AI home tutor for students of any grade and any syllabus. Initially configure it for Grade 6 Cambridge.

The product should feel like a real private tutor: the child opens the site, says “Start studying,” and has a natural voice conversation. The system independently decides what the child should learn next.

CORE LOOP

School material → Syllabus mapping → Learning plan → Explain → Ask → Listen → Evaluate → Diagnose → Remediate → Practice → Retest → Update mastery → Schedule revision → Repeat.

SOURCES

Initially retrieve school material from a configurable Gmail inbox using OAuth.

Parent can:

* Connect Gmail securely.
* Select labels/folders.
* Sync emails.
* View retrieved material.

Identify and process relevant emails and attachments: notes, homework, worksheets, tests and assignments. Support PDF, DOCX and images. Deduplicate previously processed content.

ARCHITECTURE

Curriculum must NOT be hardcoded to Cambridge Grade 6.

Model:

Syllabus → Grade/Class → Subject → Topic → Subtopic → Learning Objective

The same engine must support Cambridge, CBSE, ICSE, IB, state boards and custom syllabi.

School material should be mapped to the relevant curriculum objectives and prioritized by the tutor.

STUDENT MEMORY

Persist:

* Mastery per learning objective
* Mistakes and misconceptions
* Questions attempted
* Difficulty
* Last/next revision
* Repeated weaknesses

Classify mistakes such as conceptual, calculation, careless, vocabulary, misreading and incomplete reasoning.

VOICE TUTOR

Build a real-time voice tutor.

Child speaks → system understands → tutor responds naturally.

The tutor must:

* Explain at Grade-appropriate level.
* Ask one question at a time.
* Listen to spoken answers.
* Diagnose why an answer is wrong.
* Use hints before revealing answers.
* Adapt difficulty.
* Ask follow-up questions.
* Retest understanding.
* Maintain conversational context.

The child should experience a conversation, not a questionnaire.

LEARNING ENGINE

Before each session determine:

1. What is due for revision?
2. What is weak?
3. What school material is relevant?
4. What prerequisite is missing?
5. What is the highest-value next learning objective?

After every interaction update mastery.

Use spaced revision approximately:

1 → 3 → 7 → 14 → 30 days

Adapt the schedule based on performance.

MODEL ROUTER

Do NOT use an expensive model for every task.

Create a model abstraction/router:

* Cheapest capable model for classification, extraction and routine tutoring.
* Stronger model only for difficult reasoning, diagnosis or curriculum mapping.
* Realtime voice model for live conversation.

All model names/configuration must be environment-variable driven so models can be changed without code changes.
